# 자동몰 상세페이지 제작기 — 이어서 일하기 (인계 문서)

이 문서는 **자동몰** 작업을 새 작업 창에서 이어 가려는 사람(또는 Claude)이 제일 먼저 읽는 글이에요.
손잡이 상세페이지 제작기(버전 99)는 **다른 작업 창이 맡고 있고**, 여기서는 건드리지 않아요.

## 한눈에
| | 손잡이 제작기 (버전 99) | **자동몰 (버전 101~)** |
|---|---|---|
| 주소 | https://wjwj1935-wq.github.io/-/ | https://wjwj1935-wq.github.io/-/automall/ |
| 파일 | 저장소 맨 위 `index.html`, `src/index.fragment.html`, `version.json`, `manifest.json`, `icons/` | `automall/` 폴더 안의 같은 이름 파일들 |
| 만드는 법 | `python3 -I tools/build_site.py` | `python3 -I tools/build_automall.py` |
| 클로드 아티팩트 | https://claude.ai/artifact/Nuvi7R8acUfJJyQH2yxAX1 | https://claude.ai/artifact/RDLqUTyAQjBEuY96qABBBg |
| 저장 공간 이름 | `wj-…` (작업 상태 `wj-dp-v3`, 보관소 `wj-dp`) | `am-…` (작업 상태 `am-dp-v1`, 보관소 `am-dp`) |

- 두 앱은 **같은 github.io 주소(같은 브라우저 저장 공간)** 를 나눠 써서, 저장 이름을 일부러 다르게 했어요. 새 저장 이름을 만들 때는 반드시 `am-` 로 시작하게 해요(`wj-` 쓰지 않기).
- `작업 저장` zip 파일의 이름표(`wj:1`)는 두 앱이 같아서, 99에서 저장한 파일을 자동몰의 `파일 불러오기`로 열 수 있어요.
- **자동몰 작업에서는 저장소 맨 위 파일(99)을 고치지 않아요.** 고치는 곳은 `automall/` 와 `tools/build_automall.py` 뿐이에요. 올리기 전에 `git pull --rebase`로 99 쪽 새 커밋을 받아 와요.

## 이 앱이 하는 일
상품 이름과 사진 한 장으로 쇼핑몰(스마트스토어·쿠팡) 상세페이지를 만드는 한 파일 프로그램(바닐라 JS). 우진글로벌(정동인 대표, 문 손잡이·도어락 제조, 익산)이 직접 써요.
- 상품군 고르기(1단계 맨 위): 방문 손잡이 · 강화도어 손잡이 · 현관 롤 방충망 · 폴딩 방범 방충망 · 방충망 원단.
- **방문 손잡이**: 모든 기능(구글 AI 문 색상 이미지, 실물 합성, 3D 모형, 검수, 쇼츠 광고 영상, 치수 그림 …).
- **다른 상품군**(v101): 상품군별 규격 칸·'맞는지 확인' 카드·글 틀·설치 장면 사진 칸, 사진은 직접 넣기. AI 이미지·쇼츠 광고 영상·"한 번에 만들기"는 아직 없어요.
- 공통: 이미지 한 장으로 저장(가로 860px), 쇼핑몰에 올리기 zip, 작업 저장/불러오기, 내 상세페이지(자동 보관), 바로가기(PWA·.url), 근거가 필요한 표현 점검(v98).

## 코드 구조 (한 파일 `automall/src/index.fragment.html`)
- 상태 `S`(localStorage `am-dp-v1`), 사진은 IndexedDB `am-dp` 의 `PH` 맵. `VER=` 숫자와 화면 글자 `우진글로벌 · 버전 NNN` 이 버전이에요.
- 상품군 코드: `const GRP={…}` (상품군별 규격 칸 `rows`, 글 틀 `tpl`), `grpFill/grpSwitch`, 그리고 기존 함수(`fitCards, factsBlock, pointCards, renderPage, p1/p3/p4, preItems, gateInfo …`)를 **감싸서** 상품군일 때만 다르게 동작해요(방문 손잡이일 때는 원래 함수를 그대로 불러요). 이 부분은 `$('#btnNew').onclick=` 바로 앞에 있어요.
- 상품군 규격 값은 `S.facts.extra` 의 칸 순서대로 들어가요(그래서 저장·불러오기·내 상세페이지가 그대로 돼요). 상품군 이름은 `S.group`.
- 표현 점검: `claimScan/claimItems/claimNoteHtml` (과장 말·특허·인증·방수 등. 저장·영상·쇼핑몰 전에 알림, 과장은 확인 체크 필요).
- 새 버전 확인은 같은 폴더의 `version.json` 을 봐요(자동 업그레이드, 열린 화면에 "새 버전이 나왔어요" 단추).

## 올리는 순서 (버전 하나)
1. `automall/src/index.fragment.html` 을 고쳐요. `VER=` 숫자와 `우진글로벌 · 버전 NNN` 글자를 같이 올리고, 맨 위 버전 기록 주석에 한 줄 더해요.
2. `python3 -I tools/build_automall.py` → `automall/index.html`, `automall/version.json` 이 만들어져요.
3. 시험(아래)을 돌려요.
4. 아티팩트 게시: `Artifact` 도구로 `automall/index.html` 을 `url`=위 자동몰 아티팩트 주소로 올려요(`capabilities`는 생략해서 이어 가기).
5. `git pull --rebase` 후 커밋하고 `git push origin HEAD:main`. 열려 있는 화면에는 "새 버전이 나왔어요" 단추가 떠요. (GitHub 주소가 실제로 바뀌었는지는 직접 열어 보는 게 확실해요.)

## 시험 (Playwright, 파일로 열고 인터넷은 막아요)
`automall/dev/` 에 시험과 도구가 있어요(대표님 사진·영상은 저장소에 넣지 않았어요).
```bash
export AM_DEV=/tmp/am_dev            # 작업 폴더(아무 곳이나)
bash automall/dev/setup_dev.sh       # 폴더 만들기 · jszip/html2canvas 설치 · 가짜 시험 사진 만들기 · 단일 파일 만들기
bash automall/dev/runtests.sh groups am_separate shortcut claim staff   # 이름만 적으면 돼요
```
- **깨끗한 폴더에서 가짜 그림만으로 돌아가는 것을 확인한 시험(16개)**: `groups`(상품군) `am_separate`(99와 안 섞임) `shortcut`(바로가기) `claim`(표현 점검) `staff`(파일로 열기·저장·영상) `autoupdate` `facts` `sheet` `orient` `len` `font` `pre` `title` `careful` `catalog` `cap`.
- 아직 이 도구로는 돌려 보지 않은 시험: `ad lib wfile conv comp m3d market post video make shapes rectcap capshape capshape2`. 방문 손잡이 시험이고, 진짜 사진·영상 자료(`real_like.jpg`, `mkt_out`, 옛 기준 파일 `w/v79.html` · `w/test_v65.html` 등)가 더 필요할 수 있어요. 안 돌면 고장이 아니라 **자료가 없는 것**일 수 있으니 시험 파일 앞부분에서 필요한 파일을 확인하고, 옛 기준 파일은 `git log` 의 옛 `index.html` 로 만들어 쓰세요.
- 시험의 버전 숫자(`버전 101` 등)와 `autoupdate`·`rectcap` 시험은 버전을 올릴 때 같이 고쳐야 해요.
- 시험의 규격 값은 전부 **가짜 값**이에요. 앱은 값을 미리 채우지 않아요.

## 지켜야 할 것 (대표님이 정한 것)
1. **사실만 적어요.** 규격·숫자·특허·인증은 대표님이 준 값만. 모르면 비워 두고(노란 칸) 지어내지 않아요. 클로드 글 지시문에도 같은 규칙이 들어 있어요.
2. **키(API key)** 는 채팅·저장소·파일 어디에도 넣지 않아요. 사용하는 사람이 화면에 직접 붙여 넣어요(구글 AI 스튜디오 키, 클로드 키).
3. 과장 말(최고·최초·완벽·100%·1위 …)과 근거 없는 특허·인증은 쓰지 않아요(표현 점검이 막아요).
4. AI로 만든 사진은 연출 이미지라는 안내 문구를 지우지 않아요.
5. 한국어로, 쉬운 짧은 말로. 끝에는 **결과 · 못 해 본 것 · 다음 한 가지**를 알려요. 시험은 가짜로 했는지 진짜로 했는지 솔직하게 써요.
6. 범위를 넘겨 바꾸지 않아요. 큰 방향은 대표님이 정해요.

6. 직원용 배포: 자동몰 링크 + 바로가기 안내 그림(손잡이 제작기용 안내는 버전 99 기준이에요).
