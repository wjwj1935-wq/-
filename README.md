# 손잡이 상세페이지 제작기 (우진글로벌)

제품 이름과 사진 한 장으로 방문 손잡이 상세페이지를 만드는 프로그램입니다.
`index.html` 한 파일이 프로그램 전체이고, GitHub 페이지로 열립니다.

## 업그레이드하는 법
1. `src/index.fragment.html`을 새 내용으로 바꿉니다(안의 `VER=` 숫자를 올립니다).
2. `python3 -I tools/build_site.py` 를 실행합니다. `index.html`과 `version.json`이 새로 만들어집니다.
3. 커밋하고 `main`에 올리면 주소가 자동으로 최신이 됩니다. 열려 있는 화면에는 "새 버전이 나왔어요" 버튼이 뜹니다.

## 바로가기(홈 화면·바탕화면 아이콘)
- 프로그램 윗줄의 **바로가기** 버튼에서 만듭니다. 크롬·엣지·안드로이드는 `바로가기 설치`, 윈도우 바탕화면용은 `바로가기 파일 받기`, 아이폰은 사파리의 "홈 화면에 추가"입니다.
- 저장소의 `손잡이 상세페이지 제작기.url` 파일을 내려받아 바탕화면에 두어도 같은 바로가기입니다.
- 설치 설정은 `manifest.json`, 아이콘은 `icons/`(`python3 -I tools/make_icons.py`로 다시 만들 수 있어요)입니다.

## 버전 104에서 더해진 것 (손잡이 제작기)
- **믿음 구역(TRUST)**: 상세페이지 '회사 소개' 바로 아래에 품질관리 · A/S 관리 · 기술관리 카드와 상담 전화(063-855-3663)·상담 시간(오전 9시 ~ 오후 5시)이 들어갑니다. 4단계 편집창의 '믿음 구역'에서 고치고, 제품이 바뀌어도 회사 공통 값으로 남습니다. 칸이 비면 그 카드는 그림에서 빠지고, 전화·내용이 모두 비면 구역 전체가 빠집니다. 카드 이름(품질 · A/S · 기술 · 수출)과 전화·상담 시간만 미리 들어 있고, 카드 내용·숫자·인증은 **비워 둡니다**(사실만 직접 적어 주세요). '과장' 점검(완벽 · 최고 …)도 이 구역 글을 같이 봅니다.
- **특허 넣기 버튼**: 회사 소개의 '특허 번호 카드'에 등록증으로 확인한 2건(10-2980201 · 10-3025575)을 한 번에 넣습니다. 이미 있으면 다시 넣지 않고, 위의 '등록 특허 N' 숫자가 카드 개수와 다르면 알려 줍니다(기본 문구의 숫자는 아직 확인 전).
- **쇼핑몰에 올리기: 쿠팡 탭**: 네이버(가로 860)와 별개로 쿠팡용 이미지 묶음(상세 가로 780 · 대표 이미지 · 추가 이미지) + 올리기 안내(README) + 입력 시트(복사/CSV)를 만듭니다. 쿠팡 판매자센터의 메뉴 이름·이미지 규격·연락처 표기 규칙은 공식 문서로 확인하지 못해 화면에 모두 '확인 전'으로 적혀 있습니다. CSV는 공식 대량등록 양식이 **아닙니다**(양식 파일을 받으면 그 열 이름으로 맞출 예정). 자동으로 올리는 기능(API)은 없습니다.
- **'팔린 뒤 · 주문 수거' 점검표 탭**: 네이버·쿠팡에서 팔린 뒤 순서(주문 확인 → 발주 확인 → 포장 → 송장 → 배송 시작 입력 → 고객과 이어지는 곳)를 체크하는 표입니다. 체크 상태는 이 브라우저에만 저장되고(`wj-ord`), 고객 이름·주소·전화는 저장하지 않습니다.
- 확인 전: 실제 마켓 업로드, 쿠팡 규격, 이미지 속 전화번호 표기 허용 여부, 플레이오토·알프스 연결(양식 파일 필요).

## 자동몰 상세페이지 제작기 (따로 작동하는 새 앱, 버전 100~)
- 손잡이 상세페이지 제작기(위)에서 갈라져 나온 **별도 앱**입니다. 주소는 `/-/automall/` 이고 앞으로 상품군(방문 손잡이·강화도어·방충망 …)별 페이지로 키워 갑니다.
- 폴더 `automall/` 안에 모두 따로 있습니다: `src/index.fragment.html`(원본 조각) → `python3 -I tools/build_automall.py` → `automall/index.html`·`automall/version.json`. 업그레이드하는 법은 위와 같고, `VER=` 숫자는 100부터 올립니다.
- **저장 공간이 따로입니다**(같은 github.io 주소라도 섞이지 않게): 작업 상태 `am-dp-v1`, 사진·내 상세페이지 보관소 `am-dp`, 키·설정은 `am-…`. 손잡이 제작기는 `wj-…` 그대로입니다.
- 손잡이 제작기에서 `작업 저장`한 zip 파일은 자동몰의 `파일 불러오기`로 열 수 있습니다.
- **상품군 고르기(버전 101~)**: 1단계 맨 위에서 방문 손잡이 · 강화도어 손잡이 · 현관 롤 방충망 · 폴딩 방범 방충망 · 방충망 원단 중 고릅니다. 상품군마다 규격 칸·'맞는지 확인' 카드·글 틀·설치 장면 사진 칸이 따로이고(규격 칸 이름은 우진 스튜디오의 상품군별 필수 사양), 값은 한 칸도 미리 채우지 않습니다. 방문 손잡이 외 상품군은 사진을 직접 넣습니다(AI 이미지·쇼츠 광고 영상은 방문 손잡이만).
- 바로가기: `automall/자동몰 상세페이지 제작기.url`, 설치 설정은 `automall/manifest.json`, 아이콘은 `automall/icons/`(`python3 -I tools/make_icons_automall.py`).
