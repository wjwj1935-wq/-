# 손잡이 상세페이지 제작기 (우진글로벌)

제품 이름과 사진 한 장으로 방문 손잡이 상세페이지를 만드는 프로그램입니다.
`index.html` 한 파일이 프로그램 전체이고, GitHub 페이지로 열립니다.

## 업그레이드하는 법
1. `src/index.fragment.html`을 새 내용으로 바꿉니다(안의 `VER=` 숫자를 올립니다).
2. `python3 -I tools/build_site.py` 를 실행합니다. `index.html`과 `version.json`이 새로 만들어집니다.
3. 커밋하고 `main`에 올리면 주소가 자동으로 최신이 됩니다. 열려 있는 화면에는 "새 버전이 나왔어요" 버튼이 뜹니다.

## 키(API key)
구글 AI 스튜디오 키와 클로드 키는 사용하는 사람이 화면에 직접 붙여 넣습니다.
이 저장소에는 키가 들어 있지 않고, 들어가서도 안 됩니다.
