# 청소용품 상세페이지 전략

전략 1 · 2026-11-11. 실제로 돌아가는 전략은 [`cleaning/strategy.js`](../cleaning/strategy.js)에 있고, 이 문서는 그 이유를 적어 둔 것입니다.

## 왜 손잡이와 다른가

| | 손잡이·도어 | 청소용품 |
|---|---|---|
| 사는 이유 | 우리 문에 맞고, 모양이 마음에 들어서 | 써 보면 편할 것 같아서 |
| 먼저 보여 줄 것 | 정확한 모양, 규격 | 쓰는 장면, 쓰고 난 결과 |
| 사진이 조금 달라도 | 안 됨("받아 보니 다르다") | 분위기 사진은 괜찮음. 단, 같은 제품이어야 함 |
| 만드는 방식 | 사람이 단계마다 확인 | 사진 한 장으로 한 번에 자동 |

## 지키는 것

- **사실은 적어 준 것만.** 재질, 크기·무게, 만든 곳, 구성품은 왼쪽 "확인된 사실 적기"에 적은 것만 씁니다. 비워 두면 그 칸은 저장할 때 빠집니다. 사실이 두 가지도 안 되면 8번 표 전체가 빠집니다.
- **후기·판매량·할인·효능 숫자는 쓰지 않습니다.**
- **실제 제품 사진을 꼭 한 번 보여 줍니다.** 2번 구역에 "실제 제품 사진" 표시와 함께 들어갑니다.
- **AI 사진에는 "연출 이미지" 표시**를 기본으로 켜 둡니다. 맨 아래 안내에도 한 줄 들어갑니다.
- **글자는 AI가 그리지 않습니다.** 프로그램이 사진 위에 얹어서 깨진 글자가 없습니다.
- **모든 장면에 원본 사진을 같이 보냅니다.** 같은 제품으로 그리게 하려는 것입니다. 그래도 다르게 나올 수 있어서, 4번 칸에서 원본과 나란히 보고 그 장만 다시 만들거나 내 사진으로 바꿉니다.

## 아직 확인하지 못한 것

- **실제 구글 AI로 만든 결과.** 만드는 환경에 키가 없어서 AI 응답을 흉내 내어 시험했습니다. 화면, 조립, 저장은 확인했고, 실제 글과 사진의 품질은 키를 넣고 한 번 돌려 봐야 압니다.
- **쇼핑몰별 AI 이미지 표시 규칙**(네이버 스마트스토어, 쿠팡). 확인 전이라 표시를 기본으로 켜 두었습니다.
- **구글 요금.** 화면의 예상 금액은 손잡이 제작기에 있던 표를 그대로 쓴 대략값입니다.
